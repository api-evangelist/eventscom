# Events.com

> Events.com is a La Jolla, California event-technology company operating an end-to-end platform for
> creating, promoting, selling and discovering events — ticketing and registration, event marketing,
> sponsorship, on-site execution, analytics, virtual events, an embeddable calendar, and a consumer
> event-discovery destination. It was founded by Mitch Thrower, co-founder of Active.com / The Active
> Network.

## Developer program status

Events.com publishes **no public developer program**: no developer portal, no API documentation, no
getting-started guide, no SDK, no API pricing, no status page, no changelog, no security.txt and no
`/.well-known/*` document of any kind. `docs.events.com` exists and is branded "Events.com Docs", but it
is an empty Docusaurus scaffold with zero published pages.

Note for anyone probing this domain: **events.com serves a DNS wildcard.** Arbitrary subdomains resolve
and return HTTP 200 with the marketing homepage — including `api.`, `developer.`, `developers.`,
`status.`, `trust.` and `security.`. A 200 on this domain proves nothing without a content check.

## What does exist

Three OpenAPI 3.x contracts and one MCP server belonging to **DataGol** (internally "Saasxl"),
Events.com's data and AI platform, are served anonymously from production hosts. They are internal
platform services rather than a published product API — treat them as such.

## APIs

- [DataGol Platform API (Saasxl)](https://datagol-be.events.com/swagger-ui/index.html): Spring Boot
  backend. 865 operations, 668 paths, 518 schemas, 85 controller groups. No-code database tables
  (NoCoDb v1/v2/v3), data sources and connectors, ETL, data pipelines, DAG orchestration, data quality
  and lineage, BI pages and widgets, alerts and notification history, workflows and triggers, table
  webhooks, identity (IDP), custom agents, agent skills, and MCP connector configuration. JWT bearer auth.
- [DataGol AI API](https://datagol-ai.events.com/docs): FastAPI. 102 operations. Conversations and
  streaming agent runs, SQL parsing and dialect conversion, dashboard and widget generation, ML model
  training and prediction, research and PDF export, structured data extraction, knowledge graph, BI RAG
  indexing, Jira issue creation, MCP tool listing.
- [DataGol Python Agent API](https://datagol-python.events.com/docs): FastAPI. 10 operations. Sandboxed
  Python analysis agent — unified query, session lifecycle, Plotly retrieval, feedback.
- [DataGol MCP Server](https://datagol-mcp.events.com/): hosted MCP over `/mcp`, `/sse` and `/messages`.
  Gated on `workspace_id`, `workbook_id` and `token`, so `tools/list` is not anonymously observable.

## Known gaps

- No idempotency contract on any of 977 operations.
- No rate-limit documentation or headers; HTTP 429 declared on 14 operations only.
- 50 operations marked deprecated with no sunset date and no named successor.
- Webhooks have no signature or verification scheme and no published event-type enum.
- The two FastAPI services declare no `securityScheme` at all.
- No A2A agent card at `/.well-known/agent-card.json` or `/.well-known/agent.json` on any host.
